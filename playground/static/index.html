Part 3 · About this playground

What this is

TikTok TechJam 2026 Track 4 — a conversational shopping agent that must identify the one product the customer has in mind within at most 10 turns of questions and recommendations. Catalog: 50,000 Amazon clothing / shoes / jewelry items.

Not scored. Official scores come only from python -m evaluator.local_evaluator. This playground is for watching how the agent behaves per session, and how its memory and retrieval accuracy shift as you edit agent.py hypothesis by hypothesis.

Turn flow — two ways

  • ▶ Run the selected agent — the agent in agents/ produces both ask_attribute and the top-10.
  • Ask as the agent — you stand in for the agent: pick ask_attribute and ask. The top-10 is computed automatically by BM25 over the accumulated conversation. (The typed question is cosmetic — the simulator reads only ask_attribute.) Mix the two modes turn by turn.
  • 🗣️ The customer (official simulator) reveals up to 2 undisclosed constraints matching the asked attribute per turn. Total: 2 hard + 2 soft = 4. Green HIT when the target is in the top 10.

Three sections

  • Part 1 — what the agent sees (anonymized profile + customer messages) vs. what it must not (intent_card, target product).
  • Part 2 — the agent's actual state this turn. Query terms and exhausted attributes come straight from what the agent exposes; the BM25 rank and undisclosed title words are computed by the runner.
  • Part 3 — this text.

Agent versions

  • baseline — a copy of the official starter. Stateless BM25 on the last message only, never asks a question. Public-set Hit@10 ≈ 12.5%.
  • damin-start — spare improved baseline: BM25 over the whole accumulated conversation + a turn-by-turn attribute question ladder + light profile re-ranking.
